# litchi-flight — навык Claude Code для пролётов в Litchi Mission Hub

Строит змейку аэрофотосъёмки по KML-контуру участка **или просто по координате** (сам обводит карьер по спутнику), проверяет рельеф и настройки хаба, укладывается в лимиты и сохраняет миссию в Litchi Mission Hub.

- **Как поставить и пользоваться:** [УСТАНОВКА.md](УСТАНОВКА.md)
- **Инструкция для Claude (сам навык):** [SKILL.md](SKILL.md)
- **Что внутри:** `litchi_grid.ps1` — генератор змейки (PowerShell 5.1, ничего ставить не нужно), `terrain_check.js` — подбор шага точек по рельефу, `kml_from_point.md` — как получить KML из координаты.

Скачать: зелёная кнопка **Code → Download ZIP**, распаковать в `C:\Users\<имя>\.claude\skills\litchi-flight\`.
