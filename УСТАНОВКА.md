# Как поставить навык litchi-flight себе

1. Нужны: **Claude Code** (десктоп-приложение или CLI) и **Chrome с расширением «Claude in Chrome»**.
2. Скопировать папку `litchi-flight` целиком в
   `C:\Users\<ваше имя>\.claude\skills\litchi-flight\`
   (папку `skills` создать, если её нет). Перезапустить Claude Code — навык появится в списке по `/`.
3. Открыть Claude Code **в папке, где лежат KML участков** (результаты лягут рядом, в `Пролеты\`).
4. Включить VPN — без него Mission Hub не открывается.
5. Первый запуск: Claude откроет `flylitchi.com/hub` в своём окне Chrome и попросит войти — войти под аккаунтом Mission Hub организации один раз, дальше сессия сохраняется.
6. Дальше просто: «сделай пролёт `Участок.kml`» или «сделай пролёт по точке 55°38'54" 95°21'15", высота 100».

Навык сам проверит настройки хаба, рельеф, лимиты, сохранит миссию и покажет скриншот — границы нужно посмотреть и, если надо, поправить точки прямо в хабе, Claude подхватит.
