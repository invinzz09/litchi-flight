# Как поставить навык litchi-flight себе

## Что нужно один раз

1. **Claude Code** — десктоп-приложение или CLI, вход под своим аккаунтом Claude.
2. **Google Chrome с расширением «Claude in Chrome»** — через него Claude управляет браузером (открывает Mission Hub, импортирует маршрут, делает скриншоты).
   - В Chrome открыть Chrome Web Store, найти **Claude in Chrome** (издатель Anthropic) → **Добавить в Chrome**.
   - Нажать на иконку расширения и войти в **тот же аккаунт Claude**, что и в Claude Code.
   - Расширение ставится только руками — автоматически его установить нельзя. Это делается один раз.
3. **VPN** — Mission Hub (`flylitchi.com/hub`) без него не открывается. VPN должен работать для Chrome (системный или расширение в этом же Chrome).
4. Скопировать папку `litchi-flight` целиком в
   `C:\Users\<ваше имя>\.claude\skills\litchi-flight\`
   (папку `skills` создать, если её нет; файл `SKILL.md` должен лежать прямо в `litchi-flight\`, а не во вложенной папке из архива). Перезапустить Claude Code — навык появится в списке по `/`.

## Как пользоваться

5. Открыть Claude Code **в папке, где лежат KML участков** (результаты лягут рядом, в `Пролеты\`).
6. Включить VPN.
7. Написать: «сделай пролёт `Участок.kml`» или «сделай пролёт по точке 55°38'54" 95°21'15", высота 100».
8. При первом запуске навык сам проверит, что расширение подключено и хаб открывается, и если чего-то нет — скажет, что именно сделать. Когда хаб попросит войти — войти под аккаунтом Mission Hub организации **в окне Chrome, которое открыл Claude**, один раз; дальше сессия сохраняется. Пароль Claude не спрашивает и не вводит.

Навык сам проверит настройки хаба, рельеф, лимиты, сохранит миссию и покажет скриншот — границы нужно посмотреть и, если надо, поправить точки прямо в хабе, Claude подхватит.
