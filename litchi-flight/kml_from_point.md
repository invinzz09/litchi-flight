# KML по координате (когда контура ещё нет)

Вход: точка (из Яндекс-ссылки `whatshere[point]=lon,lat`, из таблицы «Координаты» в градусах-минутах-секундах и т.п.) и название объекта.
Выход: `<Translit>.kml` (транслит названия, пробелы → `_`, например `Sukhoy_Log.kml`) в `Пролеты\` с двумя Placemark — точка и полигон контура, — дальше обычный порядок скилла.

## Шаги

1. **Перевести координату в десятичные градусы** (DMS → `d + m/60 + s/3600`). Проверить порядок lat/lon: в Яндекс-ссылке первым идёт **долгота**; в таблицах бывают перепутаны столбцы (Говорково-1 в `Координаты (2).xlsx`).
2. **Подсказка из OSM** (необязательно, но быстро): Overpass — карьеры в радиусе 1–2 км от точки:
   ```
   curl -s -A "litchi-flight/1.0" -X POST https://overpass-api.de/api/interpreter --data-urlencode 'data=[out:json][timeout:60];(way["landuse"="quarry"](around:1500,<lat>,<lon>););out geom;'
   ```
   Контур OSM обычно устаревший (карьер разрастается) — использовать только как ориентир, не как итог.
3. **Открыть хаб** (спутник Google) и показать точку и OSM-контур поверх карты:
   ```js
   const m=GStool.map; m.setCenter({lat:LAT,lng:LON}); m.setZoom(16);
   window._pt=new google.maps.Marker({position:{lat:LAT,lng:LON},map:m,clickable:false,icon:{path:google.maps.SymbolPath.CIRCLE,scale:6,strokeColor:'#f00',fillColor:'#f00',fillOpacity:1}});
   window._osm=new google.maps.Polygon({paths:[{lat:..,lng:..},...],strokeColor:'#0ff',strokeWeight:2,fillOpacity:0,clickable:false,map:m});
   ```
   **После setZoom/setCenter из JS скриншот отдаёт старую картинку.** Лечится одним тиком колеса мыши по карте (`computer scroll` на 1 тик) — после этого скриншоты снова живые. Если вкладка «hidden» (`document.visibilityState`), скриншоты белые — попросить пользователя переключиться на вкладку хаба.
4. **Привязка пикселей скриншота к координатам.** Скриншот 1568×N, div карты 2550×M CSS-px (масштаб 1.626). Через `map.getBounds()`:
   ```js
   const m=GStool.map,b=m.getBounds(),W=1568,H=<высота скриншота>;
   const merc=lat=>Math.log(Math.tan(Math.PI/4+lat*Math.PI/360));
   const n=merc(b.getNorthEast().lat()),s=merc(b.getSouthWest().lat()),w=b.getSouthWest().lng(),e=b.getNorthEast().lng();
   window.ll2px=(lat,lng)=>[((lng-w)/(e-w)*W).toFixed(1),((n-merc(lat))/(n-s)*H).toFixed(1)];
   window.px2ll=(x,y)=>{const lng=w+(e-w)*x/W;const yy=n-(n-s)*y/H;return [+((2*Math.atan(Math.exp(yy))-Math.PI/2)*180/Math.PI).toFixed(6),+lng.toFixed(6)];};
   ll2px(LAT,LON)  // должно совпасть с положением красной точки на скриншоте — это проверка привязки
   ```
   Для деталей брать `computer zoom` на область; координаты в зум-картинке пересчитывать: `x = x0 + xz/k`, где k = (ширина зум-картинки)/(ширина области).
5. **Сначала убедиться, что виден весь объект с запасом**: отодвинуть карту так, чтобы вокруг нарушенных земель со всех сторон была видна нетронутая местность (поле, лес). Урок Сухого Лога: первая обводка была сделана по кадру, обрезанному снизу, и южный «хвост» карьера остался за контуром. **Обвести контур** по снимку: 15–30 вершин по часовой стрелке вдоль границы нарушенных земель. Включать всё антропогенное: свежие выработки, отвалы, рабочие площадки, дороги внутри, песчаные участки, а также **старые заросшие отвалы** (бугристая текстура с параллельными грядами, серые пятна, вал по кромке поля — это карьер, хоть и зелёный). Не включать: ровное поле, естественную лесную балку. Перевести вершины через `px2ll`, нарисовать жёлтым (`google.maps.Polygon`) и сделать зум-скриншот — проверить глазами, поправить вершины.
6. **Записать KML** (формат как у Google Earth, координаты `lon,lat,0`, замкнуть кольцо первой вершиной), внутри — Placemark-точка с исходной координатой и Placemark-полигон. Файл `Пролеты\<Объект>.kml`. Убрать оверлеи: `_pt.setMap(null); _osm.setMap(null); _draft.setMap(null)`.
7. **Показать контур пользователю и ждать утверждения.** Полигон нарисован поверх спутника (п. 5) — сделать скриншот так, чтобы вокруг объекта была видна нетронутая местность, и спросить: «Контур правильный? Что добавить/убрать?». Править по замечаниям и показывать снова, пока не будет явного «да». **Пролёт до утверждения контура не строить** (правило от 22.09.2026: сначала финальный KML, потом маршрут).
8. После «да» — сохранить KML; пролёт строить только если он нужен (пользователь просил или ответил «да» на вопрос «строить пролёт?»): обычный порядок скилла с шага 1 (плотный черновик → рельеф → рабочий маршрут → сохранение). Учесть: онлайн-рельеф хаба (SRTM-класс) не видит дно свежих выработок — глубина карьера в профиле не отражается, это ограничение данных, а не ошибка.

## Пример
Сухой Лог (20.09.2026): точка 55°38'54" 95°21'15" → 55.648333, 95.354167; OSM давал только старую северную выработку 2,7 га; по снимку обведён весь комплекс (северная выработка, песок на СЗ, старые отвалы на востоке, южная рабочая зона с хвостом) — 28,17 га, 8 рядов, 5,4 км, миссия `#2026-09-Sukhoy_Log-28_17ga-100m` (mk8JRFoU52). Первая версия 13,84 га была обрезана — пользователь заметил по скриншоту.
