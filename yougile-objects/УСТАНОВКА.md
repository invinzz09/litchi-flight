# Как поставить навык yougile-objects

## Один раз

1. **Claude Code** (десктоп или CLI) — тот же, что для `litchi-flight`.
2. Скопировать папку `yougile-objects` в `C:\Users\<имя>\.claude\skills\yougile-objects\` (файл `SKILL.md` — прямо в этой папке). Перезапустить Claude Code.
3. **Ключ API YouGile** — свой у каждого пользователя, делается 2 минуты, пароль через Claude не проходит:
   1. В YouGile (веб) нажать **Ctrl+Alt+Q** — появится ID компании, скопировать.
   2. Открыть https://ru.yougile.com/api-v2#/operations/AuthKeyController_create → справа в форме «Body» вписать `login` (свой e-mail в YouGile), `password` (свой пароль), `companyId` (из п. 1) → **Send API Request**. В ответе будет `"key": "…"`.
   3. Ключ (одну строку) сохранить в файл **`yougile_key.txt`** в папке проекта, где будете работать (или в `C:\Users\<имя>\.claude\yougile_key.txt` — тогда он общий для всех проектов). Ключ бессрочный; удалить можно там же в документации («Удалить ключ»).
4. **7-Zip** (https://www.7-zip.org) — чтобы навык сам распаковывал `.7z/.rar` из вложений. Без него архивы придётся распаковывать руками.
5. Для пролётов — всё из `litchi-flight\УСТАНОВКА.md` (браузер с расширением Claude in Chrome, VPN, вход в Mission Hub).

## Как пользоваться

Открыть Claude Code в папке проекта (где лежат `Пролеты\` и `yougile_key.txt`) и написать, например:

> Подключись к юджайл, изучи исходные данные в чате задачи https://ru.yougile.com/team/274c3a063d86/#PRE-2465 и сформируй KML объектов работ в WGS-84.

Навык скачает задачу и вложения в `YouGile\PRE-2465\`, разберёт объекты, покажет таблицу, задаст вопросы, сделает KML в `Пролеты\` (и пролёты, если попросить). В чат YouGile он ничего не пишет без вашего «да» на конкретный текст.

В конце навык попросит отзыв — файл `ОТЗЫВ_<задача>_<дата>.md` на **invin@bk.ru**. Это важно: навык тестовый, дорабатывается по отзывам.
