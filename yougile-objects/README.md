# yougile-objects — навык Claude Code: задача в YouGile → KML объектов работ

Подключается к YouGile по ссылке или номеру задачи, читает описание, чат и вложения, определяет объекты работ и их координаты, задаёт уточняющие вопросы и формирует KML в WGS-84. Для площадных объектов с координатами дальше строит пролёты через навык [litchi-flight](https://github.com/invinzz09/litchi-flight).

- **Установка и ключ API:** [УСТАНОВКА.md](УСТАНОВКА.md)
- **Инструкция для Claude:** [SKILL.md](SKILL.md)
- **Скрипты:** `yg_task.ps1` (скачать задачу, чат, вложения), `yg_post.ps1` (сообщение в чат — только с подтверждения)
- **Отзыв по итогам:** [ОТЗЫВ.md](ОТЗЫВ.md) → invin@bk.ru

Скачать: **Code → Download ZIP** → распаковать в `C:\Users\<имя>\.claude\skills\yougile-objects\`.
